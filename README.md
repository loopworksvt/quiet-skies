# Quiet Skies

An interactive map of a week of recorded flights over the Northeast, with a modelled estimate of how loud each one was on the ground.

Open the map at **https://loopworksvt.github.io/quiet-skies/**. It loads one state at a time; pick the state you want to start with.

- What the map shows, its limits and every credit: `about.html`.
- The flight data is from [adsb.lol](https://adsb.lol) under the Open Database License (ODbL); the processed data is in `packs/` and stays under the same licence. See `DATA-LICENCE.md`.
- Aircraft registered to private people are shown by type, model and year only.

This repository holds only the built site. It is replaced by a single new commit each time it is published.
